# Student Task Tracker

A small beginner-friendly web project to manage study tasks. Built with HTML, CSS, and vanilla JavaScript.

## Features
- Add a task
- Mark a task as completed
- Delete individual tasks
- Clear all completed tasks
- Live total, pending, and completed counters
- Saves tasks in the browser using `localStorage`
- Responsive layout for mobile and desktop

## How to run
1. Download or clone this repository.
2. Open `index.html` in any modern browser.
3. Add a task and try the checkbox/delete buttons.

No installation or external libraries are required.

## Project structure
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — task logic and local storage

## Concepts practiced
DOM manipulation, event listeners, arrays, objects, JSON, local storage, and responsive CSS.
